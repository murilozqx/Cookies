# Projeto Cookies com Modo Escuro

Projeto simples desenvolvido em HTML, CSS e JavaScript para demonstrar o uso de cookies no navegador.

O sistema permite:

- Salvar o nome do usuário em cookies
- Mostrar os cookies armazenados
- Apagar cookies
- Alternar entre tema claro e escuro
- Salvar a preferência do tema usando cookies

---

# Demonstração

## Tema Claro
- Fundo claro
- Texto escuro

## Tema Escuro
- Fundo escuro
- Texto claro
- Preferência salva automaticamente
